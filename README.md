# 🗄️ maro-plugin-mongo

Conjura scripts y guía migraciones en la tierra de los documentos.

Este plugin acerca a Maro el arte de automatizar tareas en MongoDB: ejecuta scripts, lanza migraciones y explora colecciones sin abandonar el terminal.

Ideal para quienes custodian la evolución de datos y desean gobernar cambios, backups o consultas desde una sola puerta de acceso.

---
**Comandos principales**
- Ejecutar y listar scripts sobre instancias MongoDB.
- Gestionar y aplicar migraciones.
- Navegar y consultar colecciones para asegurarse de que ningún dato quede extraviado.

Un círculo para transformar, explorar y resguardar la memoria de tus aplicaciones.
